# Chinese Narrative Chapter Lock

> Chapter-scoped terminology-locking REST API for CN→EN webnovel (xianxia/cultivation) localization by cultureBiz. POST a pasted Chinese chapter and get back locked genre terms (honorifics, ranks, energy vocabulary), title-specific entities (people, sects, skills), a character bible, and a two-column glossary CSV for downstream MT/CAT tools (DeepL, Crowdin). It is not a machine-translation engine and does not host novels; consistency is per-paste.

The API is served at https://culturebiz-xianxia-lock.onrender.com with a public OpenAPI 3.1.0
contract at /openapi.json. Calls direct to the Render host are unauthenticated; metered plans
(BASIC free, PRO $9.99/mo) are sold through RapidAPI, which fronts the API with its own
key-in-header gateway.

## API

- [POST /v1/lock](https://culturebiz-xianxia-lock.onrender.com/docs): Body {"text": "<pasted Chinese narrative>"} → locked_terms[] (zh/en/pos), title_entities[] (zh/kind), character_bible[] (zh/kind/count), csv (source,target glossary)
- [GET /health](https://culturebiz-xianxia-lock.onrender.com/health): Liveness — {"status":"ok"}
- [GET /v1/metrics](https://culturebiz-xianxia-lock.onrender.com/v1/metrics): Stranger-funnel counters, no PII
